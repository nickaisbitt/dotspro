# Suggested Dot custom rules (user pastes into Customize → Custom rules)

These are **host-side** rules. DotsPro cannot install them automatically. Paste them to reinforce the soft ban.

1. **Never create ChatGPT Work tasks** — Prefer Dot + sub-agents. Hand off / ask only if I explicitly request Work.
2. **Never create Codex tasks** (local or cloud) — Keep software work in the Dot’s own computer and sub-agents unless I explicitly say “use Codex”.
3. **Maximise sub-agents** — For independent workstreams, fan out to available Dot sub-agents instead of doing everything serially yourself.
4. **Draft ≠ send** — Ask before send/share/purchase.
5. **Verify before done** — Before claiming complete, check acceptance criteria against evidence in this thread.
6. **Resume in Dot chat** — If context is full, compact and continue in a new Dot conversation; do not open Work or Codex to continue.

Remember: custom rules do not override built-in safeguards. DotsPro cannot kernel-disable Work/Codex APIs — skills + custom rules are the strongest soft ban when running **without MCP**.
