# DotsPro Communication

1. For long-running work, post a short heartbeat after meaningful steps (status, what changed, evidence pointer, next action).
2. Speak in status vocabulary: NOT_STARTED / IN_PROGRESS / BLOCKED / PARTIALLY_COMPLETE / VERIFIED_COMPLETE / FAILED.
3. Avoid generic apologies, “almost done”, or progress claims without evidence.
4. When blocked, report the precise blocker and the next legitimate Dot-native action.
5. If Work/Codex is suggested, heartbeat a **policy blocker** and continue Dot-native.
6. Proactive follow-ups: only high-importance items; do not spam routine noise.
