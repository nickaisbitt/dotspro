# DotsPro

Skills-only ChatGPT Dot plugin — maximise Dot manager + sub-agents (`dot_native_only`), soft-ban Work/Codex. **No MCP required.**

## Install on Mac (ChatGPT desktop)

```bash
git clone https://github.com/nickaisbitt/dotspro.git
cd dotspro
bash scripts/bootstrap-dotspro-mac.sh
```

Then:

1. Quit ChatGPT (Cmd+Q) and reopen
2. Plugins Directory → **DotsPro Personal** → install **dotspro**
3. Dot → Customize → Plugins → enable DotsPro
4. Paste `~/.codex/plugins/dotspro/CUSTOM_RULES.txt` into Custom rules
5. Start a **new** Dot chat

Details: [docs/INSTALL_MAC.md](docs/INSTALL_MAC.md)
